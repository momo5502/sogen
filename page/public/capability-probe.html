Browser capability probe

Four measurements the shared-cache range bridge and the wasm memory ceiling depend on. Nothing here runs the emulator.

How to run

  1. Pick a file larger than 4 GiB below. Probe 3 reads its last 2 MiB, so the offset only lands past the 4 GiB mark if the file is bigger than that — a smaller one reports inconclusive rather than a false pass.
  2. A sparse file works and costs no disk: dd if=/dev/zero of=/tmp/sogen-big.bin bs=1 count=0 seek=5400m
  3. Copy the block at the bottom and paste it back.
